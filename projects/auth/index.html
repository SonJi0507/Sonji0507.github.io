로그인·토큰

로그인과 토큰 구조를 전면 개편한 일입니다. 재발급이 깨지던 경로를 고치고, 인증 방식을 넓혔습니다.

문제

토큰 재발급에 오류가 있었고, 인증 방식이 한정돼 접근이 좁았습니다.

역할

백엔드 개발자로 인증 구조 개편을 맡았습니다.

기술

  • JWT
  • OAuth
  • Python

기술적으로 손댄 부분

  • 토큰 재발급 흐름을 다시 구성해 실패하던 갱신을 해소했습니다.
  • 인증 방식을 확장해 들어올 수 있는 경로를 늘렸습니다.

결과

  • 토큰 재발급 오류를 해소했습니다.
  • 인증 방식 확장으로 접근성을 개선했습니다.
