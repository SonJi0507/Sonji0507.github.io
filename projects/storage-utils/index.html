공통 스토리지 유틸리티

사내 공통 백엔드 유틸리티로 스토리지와 보안 연동을 뺀 일입니다. 서비스마다 반복하던 클라우드 설정과 파일 재업로드를 라이브러리 뒤로 숨겼습니다.

문제

스토리지 연동에 클라우드별 설정이 반복됐고, 서비스 사이에 파일을 다시 올리는 공정이 남아 있었습니다.

역할

백엔드 개발자로 공통 라이브러리를 만들었습니다.

기술

  • Python
  • GCP
  • NCP
  • AWS

기술적으로 손댄 부분

  • 스토리지 연동에 필요하던 클라우드별 설정 작업을 공통 라이브러리로 모았습니다.
  • 서비스 간 파편화 때문에 생기던 파일 재업로드 공정을 제거했습니다.

결과

  • 사내 개발자가 클라우드별 스토리지 설정을 반복하지 않게 됐습니다.
  • 불필요한 파일 재업로드 공정을 없앴습니다.

링크

공개된 저장소나 제품 링크는 없습니다.
