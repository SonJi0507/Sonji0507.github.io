OurBibleNote

성경 구절 간의 관계를 그래프로 시각화하고, QT 노트를 연결하는 웹 서비스입니다. 말씀을 잇는 지도로, 구약과 신약을 한 장에서 보고 묵상의 흔적을 따라 읽습니다.

ourbiblenote.com

무엇을 만드나

한 장을 펼치면 이어진 장들이 같이 보이고, 연결된 구절을 눌러 다음 장으로 넘어갑니다. 그룹과 묵상 노트를 나눠 남길 수 있습니다. 라이브 사이트는 ourbiblenote.com입니다. 코드 저장소는 비공개라 여기에 링크하지 않습니다.

문제

성경은 구절이 서로를 가리키는데, 그 관계를 한 장의 지도로 보면서 묵상 노트까지 같은 자리에 두기가 어려웠습니다. 역본을 바꿔도 같은 자리가 이어져야 했습니다.

역할

혼자 기획부터 개발, 배포, 운영까지 맡았습니다.

기술

  • DRF
  • Python
  • Next.js
  • React
  • TypeScript
  • PostgreSQL
  • Redis
  • Docker
  • GitHub Actions

기술적으로 손댄 부분

  • Django 6 + DRF 백엔드(Python 3.14, uv)와 Next.js 15(App Router, React 19, TypeScript) 프론트엔드를 한 모노레포로 구성.
  • 성경 4개 역본(개역개정·개역한글·NIV·NLT)을 장 단위 그래프 노드로 구성하고, 노드·엣지·태그·그룹 공유 API를 설계.
  • Google·Kakao·Naver 소셜 로그인. state 검증과 Django 세션 쿠키 기반 인증.
  • 멱등성 있는 데이터 시딩. Excel에서 Bible 테이블을 거쳐 그래프 노드까지.
  • GitHub Actions CI. ruff·ty·마이그레이션 누락 검사·pytest(PostgreSQL 서비스), 프론트 lint·tsc·Vitest·Playwright E2E(CSP 위반 0건 검사 포함).
  • 홈서버에 Docker Compose로 직접 운영. PostgreSQL 18, Redis, 리버스 프록시. nonce 기반 CSP 등 보안 헤더 적용. 인프라 윤곽은 홈서버에 적었습니다.
  • AI 코딩 도구를 쓰는 워크플로. 에이전트용 가이드를 두고, lint·타입 검사·테스트·E2E를 CI로 강제해 도구가 작성한 코드도 같은 기준으로 검증.
