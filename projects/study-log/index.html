문제

업무에서 만난 도구가 공식 문서에만 있으면, 석 달 뒤에 같은 자리를 다시 찾게 됩니다. 내가 실행해 본 최소 예제와 메모를 한곳에 두고 싶었습니다.

역할

개인 학습 기록입니다. 회사 코드는 들어 있지 않습니다.

폴더

  • Celery. 태스크와 result backend, 설정을 문서로 정리한 실습.
  • RabbitMQ. producer와 consumer, Docker Compose로 브로커를 띄우는 예제.
  • async-python. 코루틴, 스레딩과 프로세스, 동시성으로 데이터를 모으는 메모.
  • Python design pattern. command, factory, observer, singleton 등 작은 구현.
  • Next.js. App Router에서 layout, not-found, 데이터 페칭, 메타데이터를 따라 만든 앱.
  • Mock server, Poetry, Ruff, uv. 도구를 처음 붙일 때의 최소 구성.
  • Vanilla JavaScript와 Flutter. 화면을 직접 만져 본 짧은 예제.
