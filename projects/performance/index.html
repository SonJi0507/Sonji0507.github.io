미피아 · 2025.05 – 2026.10

조회·응답 성능

상시로 맡은 성능·운영 개선입니다. 자주 보는 조회와 API 응답의 꼬리를 줄이고, 배포는 CI/CD로 고정했습니다.

문제

주요 테이블 조회와 API 응답이 느렸고, 배포 안정성도 손봐야 했습니다.

역할

백엔드 개발자로 인덱스, 응답 경로, CI/CD를 맡았습니다.

기술

  • SQL
  • Python
  • GitHub Actions

기술적으로 손댄 부분

  • 주요 테이블에 인덱스를 추가해 조회 경로를 줄였습니다.
  • API 응답의 p95·p99를 같은 기간에 따라 낮췄습니다.
  • CI/CD로 배포 절차를 고정해 배포 안정성과 개발 생산성을 높였습니다.

결과

  • 주요 테이블 조회 p95 500ms → 약 5ms (100배).
  • API 응답 p95 2s → 0.24s (약 8배), p99 2.4s → 0.48s (5배).

링크
