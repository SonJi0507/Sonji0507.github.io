검사 시스템 재설계

검사 시스템의 아키텍처와 DB 스키마를 다시 설계한 일입니다. 데이터를 음원 중심으로 다루도록 맞춰 다음 서비스가 갈라질 자리를 만들었습니다.

문제

검사 데이터가 음원 중심의 다음 기능과 맞지 않았고, DB 호출이 많았습니다.

역할

백엔드 개발자로 아키텍처와 스키마 재설계를 맡았습니다.

기술

  • SQL
  • Python

기술적으로 손댄 부분

  • 검사 스키마를 음원 중심으로 재구성했습니다.
  • 쿼리 가독성과 유지보수성이 떨어지던 호출 구조를 정리했습니다.

결과

  • DB 호출 횟수 30% 감소.
  • 음원 중심 관리로 서비스 다각화 기반을 마련했습니다.

링크

공개된 저장소나 제품 링크는 없습니다.
