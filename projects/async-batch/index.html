비동기·배치

손으로 돌리던 운영 작업을 비동기 처리, 배치, 스케줄러로 옮긴 일입니다.

문제

반복 운영이 수동이었고, 배치가 돌았는지 보기 어려웠습니다.

역할

백엔드 개발자로 비동기 처리와 스케줄러를 도입했습니다.

기술

  • Python
  • Celery

기술적으로 손댄 부분

  • 반복 작업을 비동기·배치로 옮기고 스케줄러에 올렸습니다.
  • 배치 작업의 안정성과 가시성을 운영에서 확인할 수 있게 했습니다.

결과

  • 수동 운영 부담을 줄였습니다.
  • 배치 작업의 안정성과 가시성을 확보했습니다.

링크

공개된 저장소나 제품 링크는 없습니다.
