1회용 이메일 도메인 수집

가입 어뷰징을 막기 위해 1회용 이메일 도메인 목록을 사람 없이 갱신하는 파이프라인입니다.

문제

1회용 이메일 도메인 목록을 사람이 갱신하면 데이터 관리 공수가 크고, 목록이 금방 낡습니다.

역할

백엔드 개발자로 수집 파이프라인을 만들었습니다.

기술

  • Python

기술적으로 손댄 부분

  • 1회용 이메일 도메인 목록을 스케줄에 따라 자동으로 최신화합니다.

결과

  • 사람 손 없이 목록을 갱신해 데이터 관리 공수를 줄였습니다.
  • 2026.07–10 동안 15회 자동 실행됐습니다.

링크

공개된 저장소나 제품 링크는 없습니다.
