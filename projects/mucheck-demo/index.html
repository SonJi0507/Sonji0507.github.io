Mucheck Demo

Mucheck AI 판별 솔루션의 데모 페이지를 만들고, 큰 파일 업로드가 서버를 누르지 않도록 경로를 고친 일입니다.

문제

대용량 파일 업로드가 느렸고 서버 부하가 컸습니다.

역할

백엔드 개발자로 데모 페이지와 업로드 경로를 맡았습니다.

기술

  • Python

기술적으로 손댄 부분

  • 판별 솔루션을 시험해 볼 데모 페이지를 구축했습니다.
  • 데모의 대용량 파일 업로드 속도를 높이고 서버 부하를 낮췄습니다.

결과

  • 대용량 파일 업로드 속도를 개선하고 서버 부하를 줄였습니다.

링크
