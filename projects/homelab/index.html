프로젝트

개인 인프라 · 진행 중

홈서버

집 Mac Mini로 개인 인프라와 배포 환경을 직접 구축·운영하는 프로젝트입니다. 앱 배포와 저장소 분리를 직접 관리하고, 외부에는 서비스에 필요한 부분만 공개합니다.

문제

데이터베이스, 캐시, 파일 저장소, 프록시처럼 오래 두는 것과 자주 교체하는 웹앱은 주기가 다릅니다. 데이터는 그대로 두고 앱만 자주 바꾸고 싶었습니다.

역할

개인 인프라를 직접 구성하고 운영합니다. 인프라 저장소는 공개하지 않습니다.

기술

  • PostgreSQL
  • Redis
  • Docker
  • Colima
  • k3s
  • Cloudflare
  • Nginx Proxy Manager
  • Beszel
  • Uptime Kuma

기술적으로 손댄 부분

  • 자주 바뀌지 않는 것은 호스트의 컨테이너로 두고, 웹앱은 Colima로 띄운 k3s에 올립니다.
  • 앱 저장소는 컨테이너 이미지만 만들고, 인프라 저장소가 그 이미지를 받아 배포합니다.
  • 파일 저장소는 앱마다 접근 권한을 나눕니다. 관리자 계정은 앱에 넣지 않고, 관리 화면은 인터넷에 열지 않습니다.
  • 외부에 공개하는 앱은 공유기 포트를 열지 않고 Cloudflare Tunnel로 연결합니다. 인증서는 Nginx Proxy Manager에서 종료합니다.
  • 머신과 컨테이너 상태는 Beszel로, 서비스가 살아 있는지는 Uptime Kuma로 확인합니다. 대시보드는 인터넷에 노출하지 않습니다.

결과

  • OurBibleNote를 이 구성 위에서 운영합니다.
  • 외부에 공개하는 서비스와 내부 관리 도구를 분리해, 대시보드와 관리 화면은 인터넷에 노출하지 않습니다.

링크

공개된 저장소나 제품 링크는 없습니다.
